## ✨ CARA BERMAIN & MENDAPATKAN UANG

Sangat mudah dan simpel:

1️⃣ **Jawab Soal**
   - Pilih jawaban yang kamu anggap paling benar.
   - Setiap Jawaban **BENAR** akan mendapatkan **+3 POIN**.
   - Jawaban salah atau waktu habis tidak mendapatkan poin.

2️⃣ **Kumpulkan Poin**
   - Main terus menerus untuk menambah saldo poin kamu.
   - Semakin banyak benar, semakin banyak poin!

3️⃣ **Pencairan Dana** 💵

   - Jika poin sudah mencukupi, kamu bisa menghubungi **CEO** untuk proses pencairan.
